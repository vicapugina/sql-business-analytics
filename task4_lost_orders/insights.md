# Задача №4. "Потерянные" заказы

## 📌 Постановка 
Определить, какие заказы доставлялись дольше всего?

## 🛠 Решение
**Что сделала:**
- через CTE выделила все доставленные заказы;
- в основном запросе отфильтровала заказы таким образом, чтобы получить наши "потерянные" заказы;
- посчитала уникальное количество таких заказов через COUNT(DISTINCT ).

## 📊 Результат

| Количество заказов |
|-------|
| 2 979 |	

Выявила 2979 "потерянных" заказов, которые были приняты курьерами, но не доставлены. Это сигнал для отдела логистики: нужно проверить причины (нехватка курьеров, технические сбои, человеческий фактор). Рекомендовала внедрить мониторинг "зависших" заказов в реальном времени.
