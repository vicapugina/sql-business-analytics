# Аналитические задачи на SQL (Karpov.Courses)

## 📌 Контекст проекта

Проект содержит решения набора аналитических задач, выполненных в рамках курса Karpov.Courses «Симулятор SQL». Работа велась с данными сервиса доставки, имитирующими реальную бизнес-среду.

**Главная цель:** не просто написать запросы, а научиться переводить вопросы бизнеса на язык SQL и интерпретировать результаты для принятия управленческих решений.

## 🛠 Инструменты и технологии

*   **Язык:** SQL (PostgreSQL)
*   **BI-инструмент:** Redash (построение дашбордов по результатам запросов)
*   **Обработка данных:** Оконные функции, подзапросы, CTE, агрегаты, JOIN

## 📂 Структура репозитория

*   `queries/` — папка с SQL-запросами:
    *   `01_basic_queries.sql` — базовые запросы (SELECT, WHERE, фильтрация)
    *   `02_aggregations.sql` — агрегация и группировка данных
    *   `03_joins_subqueries.sql` — объединение таблиц и подзапросы
    *   `04_window_functions.sql` — оконные функции
*   `insights/` — папка с бизнес-выводами по задачам

## 🧠 Основные типы решённых задач и выводы

**Примеры задач и что они дают для бизнеса:**

| Задача | Используемые SQL-инструменты | Пример бизнес-вывода / инсайта |
| :--- | :--- | :--- |
| **Расчёт ключевых метрик** | Агрегатные функции (`SUM`, `AVG`, `COUNT`), `GROUP BY`, `DATE_TRUNC` | Определение динамики DAU, WAU, удержания (Retention) для оценки роста базы пользователей. |
| **Анализ клиентской базы** | `JOIN`, `COUNT(DISTINCT)`, `ORDER BY` | Выявление ключевых клиентов для программы лояльности и понимание популярности точек продаж. |
| **Кумулятивный анализ** | Оконные функции (`SUM(...) OVER (...)`) | Построение накопительных итогов продаж для отслеживания трендов и прогнозирования выручки. |
| **Сегментация и фильтрация** | `WHERE`, `LIKE`, `CASE`, `HAVING` | Выявление категорий товаров с потенциальными проблемами (например, завышенная цена vs. количество отказов) или поиск товаров с высокой маржинальностью. |
| **Проверка гипотез** | Подзапросы, `WITH` (CTE), `CASE` | Сравнение поведения пользователей из разных групп для поиска точек роста продукта. |
