# Задача №1. Топ-10 популярных товаров (сентябрь 2022)

## Постановка 
Определить, какие товары пользователи заказывали чаще всего в сентябре 2022?

## Решение
** Что сделала: **
- через CTE отфильтровала только доставленные заказы за сентябрь 2022;
- в таблице с информацией о заказе развернула список айди товаров каждого заказа через UNNEST и убрала дубли товаров внутри одного заказа с помощью DISTINCT;
- присоединила таблицу products через LEFT JOIN по ключу айди товара, чтобы получить наименование товара;
- сгруппировала по наименованию товара с помощью GROUP BY;
- посчитала количество заказов через COUNT;
- отсортировала по убыванию и ограничила топ-10 через LIMIT
