# Задача №3. Самые долгие доставки

## 📌 Постановка 
Определить, какие заказы доставлялись дольше всего?

## 🛠 Решение
**Что сделала:**
- из таблицы с информацией о заказе взяла столбцы айди и времени создания заказа;
- через INNER JOIN по ключу айди заказа присоединила время доставки каждого заказа из таблицы с действиями курьеров;
- посчитала разницу между временем доставки и временем создания заказа через вычитание;
- отсортировала по убыванию этой разницы и ограничила результат через LIMIT 10.
